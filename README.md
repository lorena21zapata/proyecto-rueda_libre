
Rueda Libre 

Rueda Libre es un sitio web de alquiler de bicicletas en Medellín, desarrollado para ofrecer información sobre servicios, tarifas y reservas.

Servicios

- Alquiler de bicicletas.
- Recorridos guiados.
- Taller básico.

Tecnologías

- HTML5
- CSS3
- Bootstrap
- JavaScript
