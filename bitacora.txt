    Hallazgo: Error al cargar la hoja de estilos CSS

    problema identificado: Al enlazar la hoja de estilos styles.css con el archivo index.html, el navegador mostró un error MIME (text/html), indicando que no podía aplicar los estilos porque el recurso solicitado no se estaba interpretando como una hoja de estilos CSS.

    Causa: El error podía deberse a una ruta incorrecta hacia el archivo CSS o a que el servidor estaba devolviendo contenido HTML en lugar del archivo solicitado.

    Corrección realizada: Se revisó la estructura de carpetas del proyecto y se verificó el nombre y la ubicación de styles.css. También se comprobó la ruta relativa utilizada en el atributo href del elemento <link>, teniendo en cuenta que index.html está en la raíz del proyecto, mientras que tarifas.html y reservas.html están dentro de la carpeta paginas.

    Verificación: Se guardaron los cambios y se recargó la página para comprobar que el navegador pudiera encontrar y aplicar correctamente la hoja de estilos.

    Aprendizaje: Comprendí que las rutas relativas en HTML dependen de la ubicación del archivo que contiene el enlace. Además, aprendí que un error MIME de este tipo puede indicar que el navegador está recibiendo una respuesta HTML cuando espera un archivo CSS.

 12. Día 3| MiniReto 9| Punto 7
    Propiedad que se hereda: font-family. La propiedad font-family se hereda normalmente del elemento padre. En Rueda Libre, al definir font-family: var(--font-body) en el selector body, los párrafos heredan esa familia tipográfica, siempre que no exista otra regla que la sobrescriba.

    Propiedad que no se hereda: margin. La propiedad margin no se hereda automáticamente. Si se establece un margen en body, los párrafos no reciben ese mismo margen como propiedad heredada; cada elemento conserva sus propias reglas de margen.

    Resultado: La comprobación permitió reconocer que la herencia CSS transmite determinadas propiedades del elemento padre a sus descendientes, mientras que otras deben aplicarse directamente a los elementos correspondientes.

    Aprendizaje: Comprendí que la herencia ayuda a mantener estilos globales consistentes y a reducir la repetición de reglas CSS, pero no todas las propiedades se transmiten automáticamente entre elementos.

12. Día 3| MiniReto 10| Punto 2

    Problema identificado: El enlace correspondiente a la página actual no mostraba el color verde definido para la clase `.activo`, sino que conservaba el color gris establecido para los enlaces del menú.

    Causa: El selector `#menu a` tenía mayor especificidad que `.activo`. Por esta razón, la regla general del menú prevalecía sobre el color definido para el enlace activo.

    Corrección realizada:** Se aumentó la especificidad del selector de la página activa, utilizando `#menu a.activo` en lugar de `.activo`. De esta manera, los enlaces generales conservan el color gris de la marca y el enlace correspondiente a la página actual utiliza el verde Ruta. También se verificó que el atributo `id="menu"` estuviera asignado al elemento `<nav>` y que la clase `activo` se aplicara al enlace correcto en cada página.

    ```css
    #menu a {
    color: var(--color-gris-asfalto);
    }

    #menu a.activo {
    color: var(--color-verde-ruta);
    font-weight: 600;
    }
    ```

    Verificación: Se utilizó DevTools para inspeccionar los enlaces, revisar la especificidad de los selectores en la pestaña *Styles* y comprobar el color final en *Computed*.

    Aprendizaje: Comprendí que la especificidad determina qué regla CSS prevalece cuando varias declaraciones afectan a la misma propiedad. Aprendí a resolver conflictos aumentando la especificidad del selector, sin recurrir a `!important` ni a estilos en línea, y a utilizar una clase para identificar visualmente la página actual en el menú de navegación.
